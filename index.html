Subneτ Pro — IPv4 & IPv6 Subnetting Calculator

Python · Flask · REST API · JavaScript

A free, web-based subnetting tool for network engineers, students, and IT professionals — turning any CIDR input into instant, accurate results and removing the time cost and error risk of manual calculation.

  • Input: IPv4 or IPv6 addresses in CIDR format (e.g. 192.168.34.221/27)
  • IPv4 Output: Network address, broadcast address, first & last usable IP, subnet count, usable hosts per subnet, and wildcard mask
  • IPv6 Output: Prefix and address planning
  • Features: Batch processing of multiple IPs, RESTful API for workflow integration, mobile responsive, no registration or usage limits
  • Stack: Python + Flask, HTML/CSS/JavaScript, deployed on PythonAnywhere
